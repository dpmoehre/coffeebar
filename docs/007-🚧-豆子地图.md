# 007 · 豆子产地地图

> **状态**：🚧 —— 词典、接口、三种投影页面已落地并有用例；小主机 / 真豆手测未收。
> **范围**：把自己的豆卡落到世界地图上。不调外网地理编码，不上酒卡，不做热力或航线。

# ✅ 已完成：产地词典与 bean_place

`bean_place`：一张卡可有多个钉（拼配、庄园另标）。`source=gazetteer` 词典推测，`source=click` 人手点。有手定点时改产地字符串不会冲掉。

[`app/places.py`](../app/places.py) 内置咖啡产地词典（国家 / 产区 / 处理站），中英别名。按 `&` / `、` 切开，每段取最具体命中。seed 里的西达玛、蕙兰、迪马、南米纳斯、恩戈罗雷罗、耶加雪菲拼配都能对上。启动时给还没有落点的老豆补一回词典钉。

**验收**：`tests/test_places.py`。

# ✅ 已完成：地图接口与建卡自动落点

- `GET /api/map`：当前账号的钉 + 还没定点的豆（排除已删卡）+ 国家/产区百科 `origins`。
- `PUT /api/beans/{id}/places`：手写一组坐标（写锁 + 归属）。
- `POST /api/beans/{id}/places/guess`：清手定、按词典重猜。
- `create_bean` / `update_bean` 改产地或处理厂时，没有手定点就重算推测钉。
- 豆卡详情带 `places`。

**验收**：`tests/test_api.py` 拼配四钉、手定点不被改产地冲掉、删卡后不上图、别人的豆 404、`origins` 带埃塞百科。`uv run pytest` 182 passed。

# ✅ 已完成：三种投影的地图页

侧栏「地图」。同一批钉可切：

- **墨卡托**、**等积**（Equal Earth）：`d3-geo` + 随包 Natural Earth 110m，可拖可滚轮缩放。
- **地球**：`react-globe.gl`，贴图 `web/public/globe-dark.jpg` 打进仓库，不拉 CDN。没有 WebGL 时退回平面图。

在库实心琥珀钉，历史空心。点钉进豆卡；选中未定点的豆后在图上点一下写入手定点。豆卡产地旁有「去地图上点」。

# ✅ 已完成：钉上悬停弹出产地详情

鼠标移到钉上（墨卡托 / 等积 / 地球都一样）弹出卡片：这个点的产地名、经纬度、豆卡上的产区原文、对应哪支豆、账面克重、风格（烘焙 · 处理法 · 标签）。拖地图时卡片收起。点钉仍进豆卡。

地图页铺满剩余视口：拉窗口时画布和地球跟着 ResizeObserver 重算投影；窄屏图在上、列表在下且列表限高，宽屏并排。

`GET /api/map` 的钉带上 `roast` / `process` / `tags` / `balance_g` / `origin`。

# ✅ 已完成：国家 / 大产区百科悬停

国家与大产区即使库里没有对应豆卡也能悬停。百科写在 [`app/places.py`](../app/places.py) 的 `_PROFILES`：海拔、豆种、主要风味、名产。国家带 ISO 数字国码，和 `world-atlas` 的国土对齐。夏威夷只出产区圆环，不把整片美国亮起来。庄园（level 2）不出面。

`GET /api/map` 多带 `origins`。平面图按国描边，咖啡生产国略暖、可点；大产区是空心琥珀圆环，和实心豆子钉分开。地球用 `onPolygonHover` + 产区小点。豆子钉悬停仍优先。

**验收**：`tests/test_places.py` 覆盖国家/产区百科字段；`GET /api/map` 带埃塞等条目。

# ✅ 已完成：放大钉子不变大，重叠钉能分开点

平面图钉画在缩放组里时，滚轮一放大圆点跟着膨胀，同一词典坐标（比如两支都在耶加雪菲）会彻底盖住。现改为：

- 钉子 / 产区圆环按 `1/缩放` 反缩放，屏幕上大小固定。
- 屏幕距离太近的豆子钉围成一圈，细线连回真点；放大后间距够了就各自回去。
- 地球上同一经纬度的钉也绕真点错开一点，卡片仍显示原来的坐标。

散开算法在 [`web/src/geo/spread.js`](../web/src/geo/spread.js)，`node --test web/src/geo/spread.test.js` 钉住。

# ✅ 已完成：地图可单独看产区或豆子

地图工具条在「全部 / 在库 / 历史」旁边加「产区产地」「豆子」两枚芯片，默认真开。关掉其中一层，图上只留另一层；两层不能同时关。只看产区时国家高亮和圆环还在、豆子钉收起；只看豆子时反过来。从右侧点一支豆或开始定点，会自动把「豆子」层打开。
