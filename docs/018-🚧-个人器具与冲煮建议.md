# 018 · 个人器具与冲煮建议

> **状态**：🚧 —— 私人台面、管理员收录、按滤杯形状推荐冲煮方式、广场公开/领回、滤纸耗材已落地。还没做到按具体型号改各段注水。
> **前置**：冲煮方式本身见 [002](002-🚧-豆子档案与小主机架构.md)；管理员入口见 [005](005-🚧-社区版与多租户.md)。爱乐压/意式规划见 [017](017-⌛️-爱乐压与意式.md)。

## 口径

- **器具挂在账号上**，不是「谁喝的」标签。一个吧台共用一套台面。
- 用户自己登记（名字、类型、形状、照片）立刻就能影响冲煮建议，不必等管理员。
- 管理员把大家上传的收到**公共目录**，可改名、挂冲煮方式、写备注。别人能从目录领到自己台面。
- 现有冲煮「配方」仍是 V60 / Hoffmann / 4:6 / Kalita / 火山冲这套计算；目录备注叠在建议上，不另起一套段数公式。
- 过程照里的 `gear`（称盘、壶、滤杯快照）还是挂在那笔消耗上，和台面档案不是同一件事。
- 器具默认只自己看；公开后上广场，别人领走的是拷贝。和目录收录不是同一条路。

# ✅ 已完成：私人器具库

侧栏「器具」。类型：滤杯 / 手冲壶 / 磨豆机 / 称 / 分享壶 / 其他。滤杯形状：锥形 / 平底 / 浸泡；壶：细嘴。可挂照片、指定一种冲煮方式。A 看不见 B 的台面。注销清掉自己的器具和照片，已收录进目录的那条和目录照片留下。

`GET/POST /api/gear`，`PATCH/DELETE /api/gear/{id}`，`POST /api/gear/{id}/photos`。MCP：`list_gear` / `create_gear` / `update_gear` / `delete_gear` / `add_gear_photo`。

**验收**：`tests/test_gear.py`、`test_mcp.py` 的 MCP 登记与按滤杯标 owned。

# ✅ 已完成：管理员收录到目录

后台多一栏「收器具」。待收录列表能看到谁传的、什么形状。可以新建目录条目（拷一张图，避免主人以后删图把目录掏空），或挂到已有条目。目录可改冲煮方式和备注。普通人 403。

别人打开器具页能看见「目录里有、你还没领」，点一下加到台面，不必重拍。收到目录的件同时出现在王国「器具」栏，见 [020](020-🚧-咖啡王国.md)。不要另收一套。

**验收**：`test_admin_collects_gear_into_catalog`、注销后目录图还在。

# ✅ 已完成：按台面器具给冲煮建议

`GET /api/brew/methods` 登录后按滤杯标注：

- 锥形 → V60 / Hoffmann / 4:6 / 火山冲标「你有」
- 平底 → Kalita 标「你有」并建议
- 明确挂了 `brew_method` 的，以挂的为准
- 目录备注出现在该方式的 `tips` 里
- 有壶但不是细嘴，提示细嘴更好倒

豆卡冲煮下拉里带「你有 / 缺滤杯」；当前方式和台面对不上时，提示更适合哪一种。没登记器具时和以前一样，不标缺。

**验收**：`test_gear_is_private_and_methods_follow_dripper`、`test_explicit_brew_method_beats_family`。

# ✅ 已完成：器具公开到广场并领回

默认 `private`。主人可改成 `public`，出现在广场「器具」栏。别人点「领到我的台面」拷字段和照片到自己台面，原件还在主人那边。自己的不用领。同一人同一件再领一次还已有的那件（`source_gear_id`）。管理员「收器具」进目录仍是另一件事。

`GET /api/public/gear`，`GET /api/public/gear/{id}`，`POST /api/public/gear/{id}/take`。MCP：`list_plaza_gear` / `get_plaza_gear` / `take_plaza_gear`。

**验收**：`test_gear_default_private_not_on_plaza`、`test_take_public_gear_copies_photo_and_is_idempotent`。手测见 [006](006-🚧-手工验收.md)。

# ✅ 已完成：滤纸当耗材

类型多了「滤纸」。**新开一包**才记张数和价钱，不估手里旧包还剩多少。冲一杯（`as_cup`）且开着的只有一包才自动扣一张，纸钱冻进该笔消耗（钱不回溯）。没开包照常冲、不加纸钱、不进补货。多包未关不自挑，记下时再选。整袋补录不扣纸。已经开始计张、还剩 ≤20 张或用完，才上补货。原先登记成「其他」的滤纸，开包时会改成滤纸类型。广场领回滤纸不带张数。

`POST /api/gear/{id}/packs`，`GET /api/brew/methods` 带 `filter`，`GET /api/restock` 带 `filters`。MCP：`open_filter_pack`；冲一杯多包时给 `filter_pack_id`。

**验收**：`tests/test_filter.py`。手测见 [006](006-🚧-手工验收.md)。轰炸机那包不要估剩余，等用户自己点「开一包」。
