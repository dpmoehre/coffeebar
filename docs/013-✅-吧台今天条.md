# ✅ 已完成：`GET /api/today` + 豆库一条

## 目标

按当前账号、当前业务日汇总上面四块。豆库页读一次，画条。

## 实现

- 接口：`GET /api/today`，`app/today.py` 的 `snapshot`。缺的键给空数组 / `null`。
- 咖啡杯：`kind=coffee` 且 `as_cup=1` 且未撤回，`date(at, '-4 hours')` = 今日。
- 酒杯：按 `drink_serve` 去重巡数，和日历同一口径。
- 补货件数：直接数补货页三栏长度（`restock_list` + `restock_spirits` + `restock_filters`），不要新算法。
- 赏味：在库豆的 `freshness.phase` / `opened_long`。
- 上一杯：最近一笔未撤回的整杯咖啡；有秒数就带 `brew.compare` 的方案秒和粗细一句。
- 前端：`web/src/components/TodayBar.jsx` 插在豆库标题和芯片之间。切走再回来用 `listCache` 先画出上一份。

## 验收

- pytest：`tests/test_today.py` —— 凌晨 3 点算前一天；撤回的人不上芯片；别人账号的消耗不出现；整袋补录不算一杯。
- 手测：豆库顶上看得到今天自己冲过的人；切到历史/全部，条还在。见 [006](006-🚧-手工验收.md)。
