## 落地内容

- `pyproject.toml` / `.python-version`：Python 3.13，依赖只有 fastapi、uvicorn、pydantic。不用 ORM、不用 Alembic——单机单文件，`schema.sql` 每次启动幂等执行就够。
- `app/schema.sql`：`bean` / `bean_lot` / `stock_event` / `consumption_event` / `person` / `tag` / `bean_score` / `brew_guide` / `write_lock`，照片与补货表已建好待接口。
- `app/db.py`：连接、外键、WAL、业务日（凌晨 4 点分界）、统计期间起点。

## 三条硬口径的实现方式

- **账面剩余** = `可用克重 + Σ stock_event.delta_g − Σ 未撤回消耗.amount_g`
  - 可用克重 = `COALESCE(measured_g, nominal_g)`：**默认包装标称**，开袋实称有则取代
  - `intake` / `measure` 的 `delta_g` 记 0（`measure` 改的是 `lot.measured_g`，通过可用克重影响账面）
  - `adjust` 的 `delta_g` = 盘点值 − 当时账面；`close_lot` 的 `delta_g` = −当时账面（结清归零，偏差即这个数）
- **成本快照**：写消耗时把 `批次买入价 ÷ 可用克重` 冻结进那一行的 `unit_cost`，统计只读快照。
- **撤回**：只写 `voided_at` + 原因。批次若已关袋，另记一笔当天的 `adjust`（`delta_g = −amount_g`），关袋结果不被破坏。

## 验收证据

# ✅ 已完成：冲煮方案计算

`app/brew.py` 是纯函数，不碰数据库。总水 = `round(粉量 × 粉水比)`，各段按方式权重切分，**最后一段吃掉四舍五入的余数**，保证加总严格等于总水。四种方式：V60 四段、Hoffmann 一杯、4:6 粕谷、Kalita。每段给出本段用水、累计秤到、本段秒数、累计时间、手法、目标、功能、动画场景键。

豆卡上只存默认值（`brew_guide`），方案每次按当场输入重算——改粉量或比例，各段立刻跟着变。

**验收**：`tests/test_brew.py` 对 4 种方式 × 5 组粉量比例做参数化，断言加总等于总水、目标克数与时间严格累加、末段一定是无水的滴滤。

# ✅ 已完成：平均粉量与统计

`app/stats.py`。平均每杯粉量就近优先：**这支豆最近 20 杯 → 全局最近 50 杯 → 兜底 15 g**，同时给区间（只给一个平均值会掩盖波动）。杯数、见底提醒、这杯多少钱全部按它换算。

统计汇总一律**排除已撤回**流水，并把「喝掉的钱」（按每笔冻结的单价摊）和「买进来的钱」（期间新入袋的买入价）分开算，另给「在库还值多少钱」。按人、按豆、按业务日拆分。

补货清单的触发条件：在库没有了 / 低于安全库存 / 账面不够一杯 / 按近 14 天日均估算撑不了几天。

**验收**：`tests/test_stats.py` 13 个用例，覆盖兜底、分层优先级、撤回后重算、改名与停用不影响历史、按平均粉量估杯数与按 15 g 估的差异。

# ✅ 已完成：HTTP 路由与写锁

`app/main.py` 单进程同时提供 API 和前端构建产物。业务异常统一转 409，锁冲突转 423 并带上可否接管。

写锁按 002 的口径分两种行为：**网页之间是软锁**，第二处收到 423 + `can_take_over: true`，点一下接管，旧会话下次心跳会被明确告知「已被接管，你这次的修改没有保存」；**非网页来源（`X-Source: mcp`）硬拒绝**，Agent 抢不走。读接口从不占锁。

**验收**：`tests/test_api.py` 的四个锁用例 + `scripts/smoke.py` 第 8 步。

## 一处只有真跑起来才暴露的问题

FastAPI 把同步路由放线程池执行，`yield` 依赖的清理阶段可能落在另一个线程，导致 `sqlite3.ProgrammingError: SQLite objects created in a thread can only be used in that same thread`。单测用的 `TestClient` 复用线程，掩盖了它。修法是 `check_same_thread=False`——每个请求独占一个连接、不共享，放开这个检查是安全的；同时加 `busy_timeout` 避免写撞上直接报 locked。这也是保留 `scripts/smoke.py` 的原因：它对着真 uvicorn 跑。
