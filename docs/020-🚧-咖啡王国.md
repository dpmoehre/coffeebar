# 020 · 咖啡王国

> **状态**：🚧 —— 管理员把公开卡收成「同一支豆」、一人一豆杯测、评价、收藏已落地。还没拆完整公共豆种表，也没有评价审核。
> **前置**：广场去敏与认证见 [005](005-🚧-社区版与多租户.md)；私人豆卡杯测仍在自己的卡上，见 [002](002-🚧-豆子档案与小主机架构.md)。

## 口径

- **广场**还是各人公开的私卡（有买袋价和袋上克重，无剩余库存）。主人自己的 `bean_score` 不是社区分。
- **王国**才是「同一支豆」：管理员把公开卡收进 `kingdom_bean`。可新建一支，或把第二张同名卡挂到已有 `kingdom_id`（两张 MATYAZO 合成一支，大家评同一条）。
- 杯测：`UNIQUE(kingdom_id, author_id)`，一人一豆一条，可改可撤。八维 1–10 + 评语，至少填一项。自己的杯测可挂最多 8 张图（豆干/粉床/成品都行）；撤回杯测图一起走。
- 收藏：`kingdom_favorite` 开关。列表可「只看收藏」。
- 作者展示：邮箱 `@` 前一段，自己的标「（我）」。不给进价、库存、袋子。
- 收录时可把主人私卡最新杯测种子成他在王国的第一条（若还没有）。
- 注销：删这个人的王国分和收藏；`collected_by` 置空；**王国豆种和拷贝照片留下**。
- 这一刀对标器具「管理员收录」，不拆「私有持有引用公共种」那张终态表。

# ✅ 已完成：私人公开卡与王国目录分开

侧栏「王国」。没人收进来时是空的。公开卡进广场，进王国要管理员点「收进王国」。普通人 `POST /api/admin/kingdom/collect/{bean_id}` 403。没公开的卡不能收。已挂过的卡再收 409。

`GET /api/kingdom`、`GET /api/kingdom/{id}`。广场卡带 `kingdom_id`，点进去能跳到王国这支。逛广场（含「已进王国」筛选）的 MCP 见 [005](005-🚧-社区版与多租户.md)。

**验收**：`tests/test_kingdom.py`。

# ✅ 已完成：管理员收录（新建或挂到已有）

后台多一栏「收进王国」。待收录 = 已公开且 `kingdom_id` 为空。新建一支会拷封面图（避免主人以后删图把王国掏空）。给 `kingdom_id` 就挂到已有那支，`cards` 里能看到两张广场卡。可改王国里的名字和产地备注。

MCP：`list_kingdom_queue` / `collect_kingdom`（普通人 403）。

**验收**：`test_two_public_cards_share_one_kingdom`、`test_collect_seeds_score_and_one_person_one_cup`。

# ✅ 已完成：一起杯测、评价、收藏

`PUT/DELETE /api/kingdom/{id}/score`，`POST /api/kingdom/{id}/favorite`。一人一豆一条，再打覆盖自己上次的。空提交或分不在 1–10 会被拒。均分按各维有分的人算。收藏开关；`?saved=1` 只看自己收藏的。

MCP：`list_kingdom` / `get_kingdom` / `score_kingdom` / `unscore_kingdom` / `favorite_kingdom`。

**验收**：`tests/test_kingdom.py`、`test_mcp_kingdom_cupping`。

# ✅ 已完成：杯测可以上传图片

每人自己的那条杯测能挂图，和豆种封面（收录时拷的包装照）分开。先有杯测才能挂；没记下就上传会 409。一杯最多 8 张。别人看得见，只能删自己的。撤回杯测或注销，图和文件一起走；王国封面还在。

`POST /api/kingdom/{id}/score/photos`，`DELETE /api/kingdom-score-photos/{id}`。

MCP：`add_kingdom_score_photo` / `delete_kingdom_score_photo`。

**验收**：`test_cupping_photos_stay_on_score`、`test_delete_account_drops_cupping_photos`。手测见 [006](006-🚧-手工验收.md)。

# ✅ 已完成：广场与王国对跳

广场列表已收入的卡标「王国」和大家的总体均分。点开公开卡：已收入的能看王国均分并跳去杯测；管理员还能在广场上直接「收入王国」（新建一支）。王国详情列出挂过来的广场卡，点名字回到那张去敏私卡。广场雷达仍是主人自己的杯测，和王国均分分开写。

两张同名卡要挂到同一支，仍走后台「收进王国」选已有。

**验收**：`test_collect_seeds_score_and_one_person_one_cup` 里广场卡带 `kingdom` 摘要；`test_two_public_cards_share_one_kingdom` 的 `plaza_cards == 2`。
