## 已定（不要重开）

- **换算用自己的流水，不用厂家对照表。** 磨齿磨损、豆、粉量都会让网上的表失效。别人账号的杯不进你的换算（公共目录只用来认「是不是同一型号」，本期也不拿来合并样本）。
- **先能记，再能换。** 没刻度的历史杯不参与换算，也不因此作废。
- **刻度是数字 + 这台磨的尺子。** 只写「中细」不够做换算。尺子挂在磨上：单位（格 / 圈 / 微米 / 任意刻度）、最小、最大、一步。对不上的两台磨只报「B 上冲对时的中位是多少」，**不要把 25 格加成 4.2 圈**。
- **只在同一冲煮方式里换。** V60 的刻度不能直接拿去意式。爱乐压和 V60 分开。
- **「冲对了」才进样本。** 有总秒、且对照方案落在 012 / 017 的 `hold` 里。偏快走偏的那杯用来调下一刀，不拿来当换算锚点。撤回、整袋补录排除。
- **不够就不显示换算结果。** 界面写还差几杯，不要给假精确到 0.01。
- 店家豆卡上的刻度继续活在 `brew_guide.note`，那是原文，不是这台吧台磨的刻度。
- 本期不做：社区拼样本、按微米理论公式换算、自动改磨、水温换算。

## 够不够（先锁这个，别现场放宽）

一对磨 `(A, B)` + 一种方式，要同时满足：

| 条件 | 数 |
| ---- | -- |
| 两边都是台面上的磨，且都有数字尺子 | — |
| 每边「冲对了」且带刻度的杯 | ≥ 3 |
| 优先同一支豆；同豆不够再放宽到该方式下所有豆 | 同豆满 3 就只用同豆 |

还不够时：`ready=false`，带回 `need_a` / `need_b`（还差几杯）。够了才给 `estimate`。

估法（第一刀，不上回归）：

1. 各边取「冲对了」那几杯刻度的**中位数** `med_a`、`med_b`。
2. 人问「A 上 x 到 B」：
   - 两台磨 `unit` 相同（都是格，或都是圈）：`x_b = x + (med_b - med_a)`，再夹进 B 的 min/max，一步取整。
   - `unit` 不同：只回答「B 上冲对时中位是 `med_b`」，并写明不能按格对圈硬加。
3. 带上样本数和「按这支豆 / 按这种方式」。
