# 022 · 小主机外网与自动更新

> **状态**：🚧 —— 计划任务已能看 GitHub 并后台拉起网页；cpolar 要本机有客户端和 `.env` 里的 token。

# ✅ 已完成：自动看 GitHub 并拉 main

小主机用 Windows **计划任务**，不挂在 Cursor 终端里：

- `coffeebar-update`：每 **15 分钟** 跑一次 [`scripts/host-update.ps1`](../scripts/host-update.ps1)
- 登录时：启动文件夹里的 `coffeebar-host.bat`（不要求管理员）

脚本会 `git fetch`。`origin/main` 有新提交且工作区干净（只允许脏 `web/package-lock.json`、`.cursor/mcp.json`）时快进拉取，再 `uv sync` + 构建前端，然后**后台**重启 `:8000`（[`scripts/host-app.bat`](../scripts/host-app.bat)）。有别人正在改的未提交文件就跳过这次拉取，避免冲掉。

登记任务：`powershell -File scripts\host-update.ps1 -RegisterTasks`  
日志：`%USERPROFILE%\coffeebar-host.log`

# 🚧 进行中：cpolar 后台隧道

桌面安装包已解到 `%LOCALAPPDATA%\cpolar\`（3.3.18），不占 Cursor 窗口。同一脚本会后台打开 `cpolar http 8000`。口令写仓库根目录 `.env` 的 `CPOLAR_AUTHTOKEN`，不入库。公网地址写到 `%USERPROFILE%\coffeebar-cpolar-url.txt`。没填 token 时不开隧道，网页仍可内网用。
