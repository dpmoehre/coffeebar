## 已定（不要重开）

- **烘焙日挂在袋子上**（`bean_lot.roasted_on`），不挂在豆卡上。同一支豆两袋可以不是同一天烘的。
- **可缺**。袋上没印、记不清，就空着。没填的豆不从豆库消失，排序/筛选时垫底，和克价、水温同一口径。
- **赏味窗口是算出来的**，不另存一列「阶段」。改烘焙日或烘焙度，阶段当场变。
- **杯测必须记下当时处在窗口的哪一天。** 分数和「烘后第 N 天」是一对，事后改袋子上的烘焙日，**不回溯改写**已写下的杯测（和 `unit_cost` 一样冻快照）。
- 开封日还是开封日，不和烘焙日混用。没有烘焙日时，只用开封日给一句「开封已久」，不算赏味窗。
- 见底、关袋、补货仍只看克重。过了高峰只提示，不自动关袋。
- 本期不做：按庄园定制窗口、用户手改窗口天数、酒的开瓶天数、社区公共豆种上的烘焙日。

## 默认窗口（按豆卡 `roast` 文本）

从烘好那天起算，第 0 天 = 烘焙日当天。命中用「包含」：`浅` 先于 `中浅` 先于 `中深` 先于 `深` 先于 `中`。对不上用默认档。

| 烘焙 | 养豆结束（不含） | 正当时结束（不含） | 老了（含） |
| ---- | ---------------- | ------------------ | ---------- |
| 浅烘 / 中浅烘 | 10 | 28 | 56 |
| 中烘 | 7 | 21 | 42 |
| 中深烘 | 5 | 18 | 35 |
| 深烘 | 4 | 14 | 28 |
| 对不上 | 7 | 21 | 42 |

阶段键与白话：

| 键 | 白话 | 条件 |
| -- | ---- | ---- |
| `unknown` | 没填烘焙日 | `roasted_on` 空 |
| `resting` | 养豆中 | `0 ≤ 天数 < 养豆结束` |
| `peak` | 正当时 | `养豆结束 ≤ 天数 < 正当时结束` |
| `fading` | 过了高峰 | `正当时结束 ≤ 天数 < 老了` |
| `stale` | 老了 | `天数 ≥ 老了` |

另给一层 **开封提示**（不是阶段）：`opened_on` 有、且开封超过 14 天 → `opened_long=true`，卡片上可并写「开封已久」。未开封不算。

豆卡/豆库看「当前在喝那袋」；多袋未关时，和现在库存区一样，优先已开封、再按买入序。历史豆看最近关的那袋。

# ✅ 已完成：杯测记下烘后第几天

## 目标

杯测不再只是八个分数。每一笔要能回答：哪一袋、烘后第几天、当时什么阶段。豆卡上能**新打一杯**。

## 字段（`bean_score` 补列）

| 列 | 含义 |
| -- | ---- |
| `lot_id` | 可空。杯的是哪一袋 |
| `roasted_on` | 写下时的烘焙日快照，可空 |
| `days_after_roast` | 写下时算出的整数天数，可空 |
| `window_phase` | 写下时的阶段键，可空 |

服务端在 `add_score` 时算快照：有 `lot_id` 就读那袋的 `roasted_on`；人也可以当场填烘焙日。若袋子上还是空的、人填了日期，**同时写回袋子**（方便以后的赏味窗），快照仍按这次写。已经有烘焙日的袋子，杯测里改日期只改这一笔快照，不改袋子。

雷达仍看**最近一笔**。雷达下用一行白话：「烘后第 12 天 · 正当时」。历史分数列出来，每行带天数。

## 范围

- 豆卡杯测区：选袋（默认在喝的那袋）+ 八维 + 评语 + 烘焙日（有则带出，可改）。
- MCP `add_score` 增加 `lot_id` / `roasted_on`。天数和阶段不要让 Agent 手填，服务端算。
- 出表「杯测分数.csv」加：第几袋、烘焙日、烘后天数、阶段。
- 广场公开卡：可以露出最近一笔的天数和阶段，不要露出哪一袋还剩多少克。

## 不做

改画像加权公式（014 若要用「正当时的杯测」，在 014 里说）。删分、改历史分。

## 验收

**验收**：同一袋先填烘焙日再打分，快照对；事后改袋子烘焙日，旧分的 `days_after_roast` 不变；无烘焙日也能打分，阶段空；袋上为空时杯测日期会写回袋子，袋上已有则只改快照。广场卡有天数/阶段，没有 `lot_id` / `lots` / `balance_g`。

手测：【测试】豆打一杯，雷达下看得到「烘后第 N 天」。
