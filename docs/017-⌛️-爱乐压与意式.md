# 017 · 爱乐压与意式

> **状态**：⌛️ —— 只落了设计，代码未改。
> **范围**：冲煮方式补上爱乐压（浸泡）和意式。库存、扣克、谁喝的、钱的快照一律沿用现口径。不做法压、摩卡、Chemex。
> **前置**：方案计算见 [002](002-🚧-豆子档案与小主机架构.md)、`app/brew.py`。器具台面见 [018](018-🚧-个人器具与冲煮建议.md)（浸泡形状已有，还没对应方式）。时长对照见 [012](012-✅-冲煮时长与研磨建议.md)。

## 给接手 Agent

1. 先读「已定」。这两种不是手冲多两段，比例和动画都不一样。
2. 一条队列任务一个 H1。
3. `brew.plan` 继续纯函数；老方式的用例一分钟都不能红。
4. 真库存豆默认方式不要批量改成意式。

## 已定（不要重开）

- **消耗仍记咖啡粉克重**（`amount_g`）。意式 18 g 粉出 36 g 液，扣的是 18 g，不是 36 g。液重只出现在方案的「总水 / 出品」。
- **粉水比仍是 `1:x`。** 手冲常见 `1:16`；意式常见 `1:2`（粉:液）。界面在选意式时 hint 写成「粉:液，常用 1:2」，不要另做一套字段。
- **平均一杯粉量**继续按这支豆最近实际粉量分层。意式豆会自己走到 ~18 g，手冲豆还是 ~15 g，全吧台兜底仍是 15 g。
- 012 的「只比同一方式」仍然成立。意式用**更窄**的时长阈值；爱乐压仍用手冲那档（浸泡是人定的，压下去的手感不进系统）。
- 器具：滤杯 `family=immersion` 标爱乐压「你有」；意式机是新类型 `kind=espresso`，不是滤杯。没登记器具时和现在一样不标缺。
- 本期不做：法压 / 摩卡 / 虹吸 / Chemex、奶咖出品、压力曲线、意式机锅炉档案、按爱乐压纸票型号改公式。

## 方式键与默认

| 键 | 标签 | 默认粉 | 默认比 | 建议总秒 | 器具 |
| -- | ---- | ------ | ------ | -------- | ---- |
| `aeropress` | 爱乐压（倒置） | 15 | 14 | 150 | 浸泡 |
| `aeropress_upright` | 爱乐压（正置） | 15 | 14 | 135 | 浸泡 |
| `espresso` | 意式 | 18 | 2 | 30 | 意式机 |

吧台默认爱乐压走**倒置**（先泡再翻）。正置留给习惯官方用法的人。不要合成一个键再加开关。

## 爱乐压倒置（`aeropress`）

总水 `= round(粉 × 比)`。闷蒸用水 `= min(round(粉 × 2), 总水)`，余下一次注完。

| 段 | 用水 | 秒 | 场景 | 手法 |
| -- | ---- | -- | ---- | ---- |
| 注粉注水 | 闷蒸克 | 30 | `bloom` | 倒置筒里倒粉，注到约两倍粉重，搅匀 |
| 注满 | 余下全部 | 20 | `steep` | 注到总水，盖上滤帽（先别压） |
| 浸泡 | 0 | 70 | `steep` | 等；这段决定浓度 |
| 翻转压下 | 0 | 30 | `press` | 翻到杯上，平稳下压约 30 秒 |

加总 150 s。末段吃水量余数的仍是「注满」。压下没有水加入，和手冲滴滤一样 `add_g=0`。

## 爱乐压正置（`aeropress_upright`）

| 段 | 用水 | 秒 | 场景 |
| -- | ---- | -- | ---- |
| 注粉注水 | 闷蒸克 | 20 | `bloom` |
| 注满 | 余下全部 | 15 | `steep` |
| 浸泡 | 0 | 70 | `steep` |
| 压下 | 0 | 30 | `press` |

加总 135 s。不翻转。

## 意式（`espresso`）

总液 `= round(粉 × 比)`，默认 18 × 2 = 36 g。这里的「用水」是**出品克重**，不是壶里倒进去的水。

| 段 | 出品 | 秒 | 场景 | 手法 |
| -- | ---- | -- | ---- | ---- |
| 预浸 | `min(round(粉 × 0.3), 总液)` | 8 | `preinfusion` | 先润粉饼 |
| 萃取 | 余下全部 | 22 | `shot` | 看到目标液重停 |

加总 **30 s**。布粉、压粉不算进播放（人在机子上做，不占方案秒）。播放大字强调「秤到 xx g · 还剩 ss」。

## 意式时长对照（给 012 用）

差 = 实际总秒 − 方案 `total_seconds`。方向和手冲一样：偏慢是粉太细、下次粗一点；偏快是粉太粗、下次细一点。只是窗口更窄。

| 差 | 键 | 白话 |
| -- | -- | ---- |
| \|差\| < 3 | `hold` | 这次对上了，研磨先别动 |
| 3–6 偏慢 | `coarser` | 偏慢，下次粗一点 |
| > 6 偏慢 | `much_coarser` | 明显偏慢，粗一档 |
| 3–6 偏快 | `finer` | 偏快，下次细一点 |
| > 6 偏快 | `much_finer` | 明显偏快，细一档 |

012 落地时按 `method` 选阈值：滴滤 / 爱乐压用 012 原表，意式用本表。不要把意式写成「慢→细」。

# ⌛️ 未完成：播放动画新场景

## 目标

`BrewPlan` 的 SVG 现在是滤杯螺旋。爱乐压要看得出筒和活塞，意式要看得出一股液流和出品克数，不要硬套 V60 滴滤。

新场景键：`steep` / `press` / `preinfusion` / `shot`。旧场景不动。

- 爱乐压：圆筒 + 活塞下移（`press`）；`steep` 只涨液面。
- 意式：粉饼小矩形 + 向下液流；`shot` 时液面/克数涨到目标。

选意式时，表格列名「本段 / 秤到」旁加一句「出品克」，避免以为是往壶里倒。

## 验收

手测：【测试】豆切到爱乐压倒置能播完四段；切到意式大字是出品克。不要对真库存改默认方式。
