## 已定（不要重开）

- **方案建议总时间是尺子。** 同一方式、当场粉量与比例算出的 `total_seconds`，和这一杯的 `brew_total_s` 比。
- **建议按读时算**，不存一列「该粗该细」。改方案默认值不影响已经记下的秒数；对照时用**那一杯自己的** `brew_method` + `amount_g` + `brew_ratio` 重算尺子。缺方式或比例就只展示时长，不给研磨建议。
- **只比同一方式。** V60 和火山冲不要混在一条建议里。
- **整袋补录**（`as_cup=0`）没有冲煮时间，排除。撤回的排除。
- 话术用「粗一点 / 细一点 / 先别动」，**不要写死某台磨的格数**。店家豆卡上的刻度继续只活在 `brew_guide.note`。不同磨之间的数字换算见 [019](019-⌛️-磨刻度换算.md)，要等自己的「冲对了」样本够；012 先落地口头建议。
- 没播放、手填总秒也可以给建议。播放仍是主路径。
- 偏快偏慢先当研磨问题。不在这一期把水温、粉水比、注水手法折进建议。
- **阈值按方式分表，方向相同。** 上面这张给滴滤和爱乐压。意式同样是慢→粗、快→细，只是窗口窄到 3 秒，见 [017](017-⌛️-爱乐压与意式.md)。
- 器具认爱乐压 / 意式机是 [017](017-⌛️-爱乐压与意式.md) 的事，012 不要改 `user_gear` 的 CHECK。

## 阈值（总秒差 = 实际 − 方案）

| 差 | 键 | 白话 |
| -- | -- | ---- |
| \|差\| < 15 | `hold` | 这次对上了，研磨先别动 |
| 15–40 偏慢 | `coarser` | 偏慢，下次粗一点 |
| > 40 偏慢 | `much_coarser` | 明显偏慢，粗半格到一格 |
| 15–40 偏快 | `finer` | 偏快，下次细一点 |
| > 40 偏快 | `much_finer` | 明显偏快，细半格到一格 |

豆卡上的「最近这支豆」取**同一方式、未撤回、算杯**的最近 3 杯，用时长差的中位数再套上表。一杯都没有或都缺秒数：不说话。
