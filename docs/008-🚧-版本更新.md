# ✅ 已完成：手机端字号收一档

iPhone 上看「更新」标题和卡片正文偏大：页标题用 rem，根字号却只写在 `body` 上，标题仍按浏览器默认 16px 算，约 30px。

`html` 桌面 15px、窄屏 13px，并关掉 iOS 自动放大字。各页标题窄屏用 `text-2xl`，宽屏仍 `text-3xl`。卡片内边距窄屏也收一点。功能不变，只换密度。

**验收**：宽屏标题看起来和以前同一档；393 宽（iPhone 16）上「更新」不再顶满一行视觉。手测见 [006](006-🚧-手工验收.md)。

现在卡片名字和剩余先出来（先占位底纹），列表封面改用更小的一档（长边 480），一次只拉两张，哪张好了哪张淡入。豆库 / 器具 / 酒水 / 广场 / 王国同一套。点进豆卡仍看原来的清晰缩略图。
