# ✅ 已完成：基酒卡 + 酒瓶批次

卡是酒名，瓶子是批次。同样的酒再买一瓶只「再入一瓶」，酒库里始终一张卡。列表每一行能看见酒名、买入价、风味类型、酒精度。

账面剩余 = 标称毫升 + Σ `bottle_stock_event.delta_ml` − Σ 未撤回饮酒 `amount_ml`。单价快照 = 买入价 ÷ 标称毫升（元/毫升）。酒精约克数 = 毫升 × (%vol / 100) × 0.789。

消耗和咖啡共用 `consumption_event`（`kind=drink`），老库的 `lot_id NOT NULL` 走重建表迁移。

# ✅ 已完成：大类筛选 + 按含量 / 酒精度排序

`bottle.kind` 是大类（威士忌 / 金酒 / 朗姆 / 伏特加 / 龙舌兰 / 白兰地 / 利口酒 / 其他），`category` 留给细类（单一麦芽、伦敦干金）。没填大类时从品类或酒名推断；老库启动时补列并回填。酒水页用芯片筛大类，排序下拉有含量大/小（最近一瓶 `last_ml`）、酒精度高/低（`abv`），没填的垫底。默认「最近动过」且未选大类时按大类分组。

# ✅ 已完成：推荐酒单 + 鸡尾酒

侧栏「酒单」。一条指向纯饮（基酒，默认 30 ml）或鸡尾酒配方；可排序、上下架。鸡尾酒选多支基酒和默认毫升，步骤/辅料只写字不建库存。从酒单倒一杯可改实际毫升，点选「谁喝的」，可多选（一人一杯、各记一巡、库存按人数扣）。同类有好几支（多支金酒）当场选要用哪一支，不能跨类。同一支开了两瓶未关仍不自挑。任一张酒卡占锁整巡不写。一巡多行扣瓶，统计杯数和日历点子按巡算 1。酒卡上的「倒一杯」仍在，不挂巡。MCP：`list_menu` / `add_menu_item` / `set_menu_listed` / `reorder_menu` / `create_recipe` / `update_recipe` / `pour_menu`。撤回整巡用已有 `void_consumption`。

机器：见 [tests/test_menu.py](../tests/test_menu.py)。手测见 [docs/006-🚧](006-🚧-手工验收.md)。

# ✅ 已完成：配方里能换基酒

上架鸡尾酒可以先选已有配方，再换里面每一支基酒和默认毫升，一次保存后摆上酒单。编辑页「改配方」同样能改基酒，不只改名字和毫升。已经倒过的巡不跟着改。收起的酒卡不能再写进配方。

机器：`tests/test_menu.py` `test_update_recipe_swaps_spirits`；MCP `list_recipes` / `get_recipe` / `update_recipe`（`lines_json` 一次换基酒）/ `delete_recipe` / `delete_menu_item`，见 `tests/test_mcp.py`。手测见 [006](006-🚧-手工验收.md)。

# ✅ 已完成：倒酒时同类可换支

配方仍写死一支默认基酒。出品时若同一大类还有别的在库酒（两支金酒、两支朗姆），下拉选要用哪一支，库存扣选中的那支。威士忌不能顶金酒。同一张酒卡开了两瓶，仍要指定第几瓶。

# ✅ 已完成：删酒卡

对标豆卡。`DELETE /api/spirits/{id}`：没未撤回倒酒时整张物理删（瓶子、照片、酒单/配方引用一起走）。有未撤回倒酒时确认框两选，不必先撤回：

- `?mode=keep`：从酒库收起（`bottle.deleted_at`，开着的瓶关上）。杯数和花掉的钱留在统计里。剩下来的毫升不再算「在库」。纯饮和含这支酒的鸡尾酒酒单条目拿掉。
- `?mode=wipe`：连流水一起物理删。鸡尾酒一巡里只抹这支酒的行，另一支的流水还在。空了的配方和酒单条目一起走。
- 不带 `mode` 仍 409。撤回后再删也不带 mode，走物理删。

界面：酒卡页右上「删除酒卡」。MCP：`delete_spirit`。别人的酒 404，别的会话占 `bottle:{id}` 时 423。

**验收**：`tests/test_spirits.py`——无流水直接删后详情 404 / 酒库空 / 照片没了 / `bought` 归零；有未撤回不带 mode 409；`keep` 后 `spent`/`bought`/`drink_cups` 还在、`on_hand` 归零；`wipe` 后钱和杯归零；只删该删的那张；别人 404；占锁 423；酒单/配方引用时 wipe 不炸；鸡尾酒两支只抹一支。手测见 [006](006-🚧-手工验收.md)。不要 wipe 格兰杰。
