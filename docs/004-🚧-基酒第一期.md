# ✅ 已完成：基酒卡 + 酒瓶批次

卡是酒名，瓶子是批次。同样的酒再买一瓶只「再入一瓶」，酒库里始终一张卡。列表每一行能看见酒名、买入价、风味类型、酒精度。

账面剩余 = 标称毫升 + Σ `bottle_stock_event.delta_ml` − Σ 未撤回饮酒 `amount_ml`。单价快照 = 买入价 ÷ 标称毫升（元/毫升）。酒精约克数 = 毫升 × (%vol / 100) × 0.789。

消耗和咖啡共用 `consumption_event`（`kind=drink`），老库的 `lot_id NOT NULL` 走重建表迁移。

# ✅ 已完成：大类筛选 + 按含量 / 酒精度排序

`bottle.kind` 是大类（威士忌 / 金酒 / 朗姆 / 伏特加 / 龙舌兰 / 白兰地 / 利口酒 / 其他），`category` 留给细类（单一麦芽、伦敦干金）。没填大类时从品类或酒名推断；老库启动时补列并回填。酒水页用芯片筛大类，排序下拉有含量大/小（最近一瓶 `last_ml`）、酒精度高/低（`abv`），没填的垫底。默认「最近动过」且未选大类时按大类分组。

# ✅ 已完成：推荐酒单 + 鸡尾酒

侧栏「酒单」。一条指向纯饮（基酒，默认 30 ml）或鸡尾酒配方；可排序、上下架。鸡尾酒选多支基酒和默认毫升，步骤/辅料只写字不建库存。从酒单倒一杯可改实际毫升；多瓶未关不自挑；任一张酒卡占锁整巡不写。一巡多行扣瓶，统计杯数和日历点子按巡算 1。酒卡上的「倒一杯」仍在，不挂巡。MCP：`list_menu` / `add_menu_item` / `set_menu_listed` / `reorder_menu` / `create_recipe` / `update_recipe` / `pour_menu`。撤回整巡用已有 `void_consumption`。

机器：见 [tests/test_menu.py](../tests/test_menu.py)。手测见 [docs/006-🚧](006-🚧-手工验收.md)。
