# ✅ 已完成：异地备份

## 目标

每天（或每次启动后）有一份能还原的 zip：**不在小主机系统盘上**。现有 `scripts/backup.bat` / `scripts/backup.sh` 继续用 SQLite 在线 `backup()`，不要改成直接拷 WAL 文件。

## 实现

- `app/backup.py`：`pack` / `write_zip` / `extract_zip` / `prune`（默认留 14 份）。`python -m app.backup pack|restore`。
- 目标目录：`COFFEEBAR_BACKUP_DIR`；没设则 `~/coffeebar-backup`，并印「这份备份还在本机，盘坏会一起没」。
- `scripts/backup.sh` / `backup.bat` 改调 `python -m app.backup pack`。
- 本机还原：`scripts/restore.sh` / `restore.bat`。服务还在 `:8000` 且目标是当前 `data/` 时拒绝，除非 `--force`。演练用 `--dest` 指到临时目录。
- 定时示例：`scripts/backup-schedule.md`（任务计划 / launchd / cron）。不入库口令。
- zip 根下仍是 `coffeebar.db` + `photos/`，云上 `POST /api/ops/restore` 能吃。

## 验收

# ✅ 已完成：第一人接手必须确认

## 目标

有孤儿数据时，谁先注册也不能在不知情下领走吧台账本。默认是空库；接手是显式动作。

## 实现

- `POST /api/auth/register` 不再自动 claim。可选 `claim`：`take` | `leave`。
- 有孤儿且没带 `claim` → **400** JSON：`{error:"orphans", message, beans, bottles, people, recipes}`（`JSONResponse`，不是 FastAPI 默认 `detail` 字符串）。
- `take`：建号并 `claim_orphans`（`bean` / `bottle` / `person` / `recipe` / `menu_item` / `drink_serve`，表在才更新；有 `user_gear` 也挂）。`claimed: true`，写 `claimed_at`。
- `leave`：建号不 claim。`can_claim` = 仍存在账号里 `id` 最小的那个。第二人 `take` → **403**。
- 没有孤儿时忽略 `claim`，普通注册。
- `POST /api/auth/claim-orphans`：最早的号事后接手。
- `GET /api/me` 带 `claimed` / `can_claim` / `orphans`。
- 网页：注册 400 后二选一；侧栏持续提示「还有没主人的库存」。

## 验收

- 机器：`tests/test_auth.py` 的 `test_first_account_claims_orphans` / `test_leave_orphans_then_claim`。空库注册仍 201。
- 手工：空号对**临时库**走两按钮。不要在小主机真库存上试 `leave`。见 [006](006-🚧-手工验收.md)。

# ✅ 已完成：真库存号注销前导出

## 目标

侧栏「注销账号」仍可清掉**自己的**私库，但接手过孤儿、或当前仍握有从本机迁来的豆/酒的号，必须先拿到备份。服务端是闸门。

## 实现

- 真库存号：`account.claimed_at` 有值，或名下有未删的豆/酒（老号兜底）。`claimed_at` 走 `ADDED_COLUMNS`。
- 真库存号 `POST /api/auth/delete` 没有有效 `export_token` → **400**「先导出备份」。
- `GET /api/ops/backup`：仅真库存号，下载整库 zip，头 `X-Export-Token`，15 分钟，`auth_token.purpose='export'`。空号 403。
- 空号、名下无豆无酒：邮箱+密码即可注销。
- 网页：先「下载备份」，再「确认注销」。
- 注销 SQL 包在事务里；`PRAGMA foreign_keys=OFF` 在 `BEGIN` 之前（SQLite 事务内改这个要等 COMMIT 才生效）。照片文件 **COMMIT 后再删**。

## 验收

- 机器：`test_delete_empty_account` 直接过；`test_delete_account_wipes_only_self` 不带 token 400，带新 token 才删。
- 手工：空号或【测试】号。真库存号只测到「不带备份被拒」。不要在小主机上真注销。见 [006](006-🚧-手工验收.md)。
