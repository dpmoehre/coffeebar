# 015 · 拍豆卡直接建档（MCP）

> **状态**：✅ —— 查重、建卡顺带挂图、工具五步说明已落地。服务端仍不识字。
> **范围**：人把店家豆卡 / 包装拍给 Cursor，Agent 读图、对人复述字段、再写入现有建卡接口。照片仍进 `data/photos/`，`kind=card`（或包装 `pack`）。
> **前置**：MCP 与写锁见 [002](002-🚧-豆子档案与小主机架构.md)；`create_bean` / `add_bean_photo` / `create_bean_lot` 已有。烘焙日字段见 [016](016-✅-烘焙日与赏味窗口.md)，写进袋子 `roasted_on`。

## 给接手 Agent

1. **不要在 FastAPI 里接视觉模型、不要加 OCR 依赖、不要把照片打到第三方识别 API。** 读图的是 Cursor（对话里已经能看图）。本仓库只补「字段清单 + 查重 + 一次写入挂图」。
2. 关袋、wipe、真库存已有豆，仍然必须人明确说。建档前要查重。
3. 密钥不入库。

## 已定（不要重开）

- **服务端不识字。** 小主机不跑本地大模型。识别在 Agent 侧完成。
- **先复述，再写入。** 工具或工作流必须让 Agent 把读到的字段用人话列出来，人对了才调创建。工具自己不得在没列出字段的情况下静默建卡。
- **一张卡、一袋、至少一张 `card` 或 `pack` 图** 是一次建档的最小闭环。豆盘图可后补。
- **查重。** 同账号下名字或「产地+处理法+烘焙」高度像已有卡时，先列出已有 id，问是「再入一袋」还是「仍要新建」。
- 网页占锁时仍硬拒绝，不接管。
- 价格、克重读不清就空着，标「待入袋」，不要猜。
- 本期不做：网页一键「拍照自动填表」（没有服务端识图就会变成假智能）、酒标识图、批量文件夹导入。

## Agent 必须试图读出的字段

和 `create_bean` 对齐，读不清就标 `null`，不要编：

- 名字、产地、豆种、处理厂/庄园、海拔、处理法、烘焙
- 建议水温、粉量、粉水比、店家冲法备注（滤器 / 研磨刻度 / 水质 / 目标时长）→ `brew_*` / `brew_note`
- 袋上克重、价钱、购入日、**烘焙日**（011 有列就 `roasted_on`）
- 风味标签（包装上的风味词，输入即标签）

图本身：豆卡纸 → `kind=card`；能看清袋子正面 → 可再挂一张 `pack`。

# ✅ 已完成：查重 + 建卡时直接挂图

## 目标

现在必须先 `create_bean` 拿到 id，再 `add_bean_photo`。拍卡建档会断成两步，图还容易忘挂。

- `create_bean` 增加可选 `photo_path` + `photo_kind`（默认 `card`）。有路径就建卡成功后立刻挂图，失败要回报（卡已建、图没挂上也要说清楚）。
- 新工具 `find_similar_beans(name=?, origin=?, process=?, roast=?)`：只读，返回最多 5 张已有卡的 id/名字/产地，供查重。不要在 `create_bean` 里偷偷拒绝重名（店里可能真有两袋写法一样但配方不同，人决定）。

## 落地

- HTTP：`GET /api/beans/similar`（写在 `{bean_id}` 前面），只查当前账号未删卡。
- 名字像：去掉空白后相等，或较短一段（至少两字）被包含。只给产地或只给烘焙不会扫到所有埃塞 / 浅烘。
- MCP `create_bean` 先 `POST /api/beans`，再走现有挂图。本机路径不进 HTTP JSON。图失败返回豆卡 + `photo_error`。

## 验收

pytest：带本机一张小 JPEG 建卡，详情里有 `kind=card` 的照片；路径无效时卡仍在、报图失败。手测见 [006](006-🚧-手工验收.md)。不要对真库存已有豆重复建档。

# ✅ 已完成：MCP 工具说明书写成工作流

## 目标

`create_bean` / `add_bean_photo` / `find_similar_beans` 的 docstring 写成一段固定工作流，Cursor 不用猜：

1. 看图，按字段清单抽出，读不清写空。
2. `find_similar_beans`。
3. 对人复述。没点头不写。
4. `create_bean`（带图路径）或对已有卡 `create_bean_lot` + 挂图。
5. 回报 id，提醒刷新豆库。

`.cursor/mcp.json` 的 `namespaceUseInstructions` 补一句：「用户丢豆卡/包装图要建档时走这套，不要只建卡不挂图，不要猜克重价钱。」正文同样写进 `mcp_server` 的 `instructions`（Cursor 对话里看到的那句来自这里）。

## 不做

改写锁、改照片转码尺寸、给网页加识别按钮。

## 验收

本机空号：一张虚构豆卡图走完五步，豆库有卡有图；再丢同一张，Agent 先问是否再入一袋。记在 [006](006-🚧-手工验收.md)。
