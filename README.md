# coffeebar

公司咖啡吧里的**个人手冲 / 调酒工作台**。远程：[github.com/dpmoehre/coffeebar](https://github.com/dpmoehre/coffeebar)。

用来把豆子和酒管清楚：豆卡、照片、库存、冲煮怎么倒、谁喝了、一杯多少钱、该补货了；酒有酒单、酒瓶、鸡尾酒和基酒配方；还能看日历、出表、按人出画像。

**不是点单点菜，不是后厨 KDS，也不是给全公司下单的系统。**

应用代码还在落地前。约定与数据模型见 [docs/002-🚧-豆子档案与小主机架构.md](docs/002-🚧-豆子档案与小主机架构.md)。页面气质可点 [_Doc/2026-09-04-ui-样张/index.html](_Doc/2026-09-04-ui-样张/index.html)。

## 能做什么

### 豆子

- **独立豆库**：一眼看所有在库豆子还剩多少，带进度条。21 寸吧台屏按四列排。用完的豆进「历史」，风味和冲煮记录保留。
- **排序与筛选**：浅/中/深烘、酸甜香、剩余、评分、地区、水温、开封日；自由标签点一下就筛。
- **豆卡**：产地、处理法、风味、杯测雷达、价格、每杯成本。照片分包装袋和豆盘，没开封可以先缺豆盘图。同样的豆再买只「再入一袋」，不用新建卡。库存用图标显示袋数、克数、杯数。
- **包装克重 ≠ 实重**：批次分记标称、开袋实称、账面剩余。见底只提醒；「这袋用完」要人确认，偏差记进流水。
- **消耗**：冲一次扣克重，可打「谁喝的」。消耗速度画曲线，低库存进补货清单；补货条目可上传对照图片。
- **冲煮指导**：单独占一整行（不和库存挤宫格）。算出每一段的用水、秒数、累计时间、手法、目标与功能，可播放动画并记下实际用时。

### 酒

- **基酒**：酒名、买入价、风味类型、酒精度（% vol）列在一起能看见；同样的酒再买只加一瓶，不新建名字。
- 推荐酒单、鸡尾酒配方、自制基酒（浸泡/糖浆）配方。
- 倒一杯记毫升；和豆子共用「谁喝的」与补货清单。

### 统计与画像

- **统计**：一进来先看数字——这段时间消耗了多少克豆子、多少毫升酒、酒精大约多少克、喝掉多少钱、买进来多少钱、多少杯；再看曲线和按人拆开。
- **日历**：哪天冲了咖啡、哪天喝了酒。
- **出表**：CSV（Excel 能直接开），含库存、流水、分数、标签、关袋偏差、统计汇总。
- **用户画像**：按人名从流水自动总结爱喝什么样的（浅烘高酸、常点的酒等），并写出这个人喝了多少克豆、多少酒精、花了多少钱。样本太少不强行下结论。

### Cursor 用 MCP 直接记账

准备好豆袋照片和豆卡文字后，可以让 **Cursor 经 MCP 直接写入** 小主机上的库，不必在网页里一项项手填。网页和 MCP 走同一套接口与写锁，写完刷新豆库就能看见。

计划中的能力（落地后在 Cursor 里打开本仓库的 MCP）：

| 你在 Cursor 里说 | MCP 去做 |
| ---- | ---- |
| 用这张图和下面字段建一张豆卡 | 建豆、建批次、拷照片进 `data/photos/` |
| 给西达摩补开袋实称 198 g | 改当前批次 |
| 我刚才用了 16 g，谁喝的：小王 | 记消耗流水 |
| 这袋冲完了 | 关袋并结清偏差 |
| 豆库还剩哪些浅烘 | 查询列表 |
| 这个月喝了多少豆、多少酒、花了多少钱 | 汇总统计数字 |

MCP 只连本机（或公司内网）上的 coffeebar，口令与数据不进 Git。详细工具表见 [docs/002](docs/002-🚧-豆子档案与小主机架构.md)「MCP：让 Cursor 接管记账」。

## 谁在哪用

| 场景 | 设备 | 差别 |
| ---- | ---- | ---- |
| 日常吧台 | Win11 小主机 + 21 寸屏 + 键鼠 | 宽屏布局，这是主屏 |
| 拍照、站着冲 | iPhone / iPad | 单列、相机和冲煮动画靠前 |
| 换一台电脑 | 公司内网 Mac / Windows | 同一套功能，随窗口变布局 |
| 外出 | 必要时临时 cpolar | 功能相同，必须有口令 |

功能全端一样，只换布局。同一条豆卡/酒瓶同时只允许一个写会话（网页和 MCP 一起算），避免互踩。

**小主机**：Windows 11，16 GB，Ryzen 7 PRO 7850H + Radeon。既是服务器也是工作台。内网为主。

## 怎么跑（落地后）

目标是少步骤，不用 Docker。

1. 在小主机上跑一次 `install.bat`（装好 uv、Node，同步依赖，构建前端）。
2. 日常双击 `start.bat`，浏览器打开 `http://localhost`。
3. 需要备份时跑 `backup.bat`，拷走 `data/`（库文件 + 照片）。

密钥和口令写本机 `.env`，不要提交。换机器：拷仓库 + 拷 `data/` + 再装一次。

当前还没有这些脚本和运行入口，先不要当已经能安装。

## 技术形态（已选定）

- 网页：Vite + React + Tailwind + anime.js（冲煮 SVG）。
- 服务：FastAPI（uv）+ SQLite + 本地照片目录。
- 入口：Caddy 反代；本机 `localhost`，内网用主机名或 IP。
- MCP：本机进程，调用同一套 FastAPI / 同一份 SQLite。
- 视觉：深色 espresso、奶油字、琥珀点缀；样张以 [_Doc/2026-09-04-ui-样张/画像.png](_Doc/2026-09-04-ui-样张/画像.png) 为准。
