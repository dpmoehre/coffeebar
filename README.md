# coffeebar

公司咖啡吧里的个人手冲 / 调酒工具。远程：[github.com/dpmoehre/coffeebar](https://github.com/dpmoehre/coffeebar)。

**不是点单点菜系统。** 管豆子（独立豆库页一眼看剩余和进度条，可按烘焙/风味/评分/地区/水温/开封日等排序，可自由打标签并筛选；档案、冲煮动画、价格与每杯成本、维度打分、谁喝的、消耗曲线、补货）和酒（酒单、酒瓶、鸡尾酒与基酒配方），带日历、CSV 出表，以及按「谁喝的」自动出用户画像（爱喝什么样的）。页面气质样张见 [_Doc/2026-09-04-ui-样张/](_Doc/2026-09-04-ui-样张/)。包装上的克重和实称可能不一致：开袋可补实重，见底要人确认「这袋用完」，偏差记进流水。

运行在一台 Windows 11 小主机上，安装和启动走脚本、尽量少步骤；公司内网访问，必要时临时走 cpolar。小主机、手机和其他电脑**功能相同**，只换页面布局。全站统一现代吧台 UI 与动效。同一条资源同时只允许一个写会话，避免多端互踩。

架构与运行环境见 [docs/002-🚧-豆子档案与小主机架构.md](docs/002-🚧-豆子档案与小主机架构.md)。应用代码尚未落地。
