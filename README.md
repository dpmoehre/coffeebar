# coffeebar

公司咖啡吧里的**个人手冲 / 调酒工作台**。远程：[github.com/dpmoehre/coffeebar](https://github.com/dpmoehre/coffeebar)。

用来把豆子和酒管清楚：豆卡、照片、库存、冲煮怎么倒、谁喝了、一杯多少钱、该补货了；酒有酒单、酒瓶、鸡尾酒和基酒配方；还能看日历、出表、按人出画像。

**不是点单点菜，不是后厨 KDS，也不是给全公司下单的系统。**

**豆子已经能跑**；**基酒能建档、记库存、倒一杯**；**推荐酒单（纯饮 + 鸡尾酒）也能上架、改毫升倒一巡**（自制基酒还没做）。**Cursor 可经 MCP 记账**。约定见 [docs/002-🚧](docs/002-🚧-豆子档案与小主机架构.md)，豆子进度见 [docs/003-🚧](docs/003-🚧-豆子第一期实现.md)，基酒与酒单见 [docs/004-🚧](docs/004-🚧-基酒第一期.md)。页面气质可点 [_Doc/2026-09-04-ui-样张/index.html](_Doc/2026-09-04-ui-样张/index.html)。

## 能做什么

### 豆子

- **独立豆库**：一眼看所有在库豆子还剩多少，带进度条。21 寸吧台屏按四列排。用完的豆进「历史」，风味和冲煮记录保留。
- **排序与筛选**：浅/中/深烘、酸甜香、剩余、**克价**、评分、地区、水温、开封日；自由标签点一下就筛；也能搜名字、产地。没填价钱的豆子不藏，按克价排时垫底。
- **克价**：每张卡露出元/克（买入价 ÷ 可用克重；一支豆多袋按还剩的克加权）。喝完进历史也留着，还能按价钱翻旧豆。
- **豆卡**：产地、豆种、处理厂/庄园、海拔、处理法、风味、杯测雷达、价格、每杯成本。照片分包装袋、豆盘和**店家豆卡**（那张印参数的纸，拍下来留档；选封面时会跳过它，缩成方图只剩一片字），三种都可缺，没开封可以先缺豆盘图。四产区拼配豆照豆卡原样填，产国/品种/处理法写几个都行。
- **产地地图**：侧栏「地图」把豆卡落到世界地图上。产地是自由文本，内置咖啡词典对上国家 / 产区 / 常见处理站；拼配一张卡多个钉；对不上或要精确到庄园就在图上点一下。悬停国家或大产区看当地海拔、豆种、主要风味和名产（即使库里没有对应豆卡）。可只看产区产地、只看豆子，或两层一起。放大时钉子屏幕大小不变；同一产区多支豆会围开，避免盖住点不到。同一批钉可切墨卡托、等积（Equal Earth）、真 3D 地球。不调外网地图服务。酒卡第一期不上图。
- **删得掉建错的卡**：豆卡 / 酒卡页右上都能删。没记过消耗就整张抹掉。有没撤回的记录时当场选：真喝过就「留下花掉的钱」（库里没卡了，统计里杯数和钱还在）；测试卡就「连记录一起抹」。删酒卡时，酒单里这支酒的纯饮和含它的鸡尾酒条目一起拿掉。
- **一支豆买几袋**：同样的豆再买只「再入一袋」，不用新建卡——**豆库里始终一支豆一张卡**，克重按未关袋汇总，多袋时标「共 N 袋」，袋子明细在豆卡页里按买入顺序列成「第 1 袋 / 第 2 袋」。编号不会因为开封换位置而改变，冲煮时选哪袋、消耗日志里扣的是哪袋，都对得上。
- **先建卡后称重**：净含量没印在包装上（纸罐装常见）可以不填，先建一张卡，标「待入袋」跟着在库出。称过再入袋；这种豆不会进补货清单——豆子在手上，缺的是称重录入，不是缺货。
- **还剩多少克**：这是库存区最主要的信息——直观看还有多少量、还能冲几杯、要不要补。刚拆袋通常不会去称，**默认就按袋上印的标称克重开始扣**；想较真时才补一笔开袋实称。见底只提醒；「这袋用完」要人确认，偏差记进流水。
- **平均一杯用多少粉**：每次冲煮记的是**当次实际用量**（不是每次都写 15 g），系统再从这些实际值统计出「我平均一杯用多少粉」并给出区间。豆库和豆卡的「还能冲几杯」、见底提醒、这杯多少钱，全都按这个数换算，不用假想值。
- **消耗**：冲一次时**自己选用哪一袋**（列出各袋的剩余、单价、开封日，不自动挑），扣克重并记「谁喝的」。冲煮记录可挂称豆、粉床、冲完、器具（称盘、壶、滤杯）的过程照，都可缺。消耗速度画曲线，低库存进补货清单；补货条目可上传对照图片。酒不够一杯或瓶子空了也会出现在同一页。
- **谁喝的可以随便管**：人能新增、改名、停用、**删除**。改名不动历史；停用只是从选人列表收起来；删除是真删，但他名下的流水会留下变成「没记」——豆是真扣过的、钱是真花过的，删个人不该让库存和统计总数跟着变（删之前会告诉你有多少条会变「没记」）。每个人有一页追踪记录。记一笔记错了能**撤回**——库存加回去、钱退出统计，流水先划掉不删；划掉的那笔可以再**彻底删除**（库存不再动）。
- **冲煮指导**：单独占一整行（不和库存挤宫格）。按你当场输入的粉重和粉水比即时算每一段的用水、**水粉比**、秒数、累计时间、手法、目标与功能；豆卡上只存默认值，可播放动画并记下实际用时。方式有 V60 四段、Hoffmann、4:6 粕谷、Kalita、**多段式火山冲**（细水流一路咬住中心把粉层顶成火山口，段时正好落在 2'15"）。
- **店家推荐直接存成默认**：豆卡上印的粉水比、水温、手法可以在建卡时一起填，成为这支豆的默认参数；滤器、研磨刻度、水质这类算不进公式的原文另存一条备注，冲煮区一直显示。后来改粉量比例不会把它抹掉。

### 酒

- **基酒**：酒名、买入价、风味类型、酒精度（% vol）列在一起能看见；按威士忌 / 金酒等大类筛选，可按含量（标称毫升）和酒精度排序，也能搜酒名、风味。同样的酒再买只加一瓶，不新建名字。酒卡上也能「倒一杯」，按毫升扣，单价按「买入价 ÷ 标称毫升」冻结。
- **推荐酒单**：侧栏「酒单」。一条指向纯饮（默认 30 ml）或鸡尾酒。可上下架、排序、按名字或材料搜。鸡尾酒选多支基酒和默认毫升；也可以先选已有配方再换里面的基酒，一次保存。冰块、汤力写在步骤里，不建库存。从酒单倒一杯时每支都能改实际毫升；同类有好几支（多支金酒）当场选要用哪一支。同一支开了两瓶未关不自挑。鸡尾酒拆成多笔扣瓶，日历和统计按「这一巡」算 1 杯。
- **自制基酒**（浸泡 / 糖浆）还没做。
- 倒一杯记毫升；和豆子共用「谁喝的」。不够一杯或瓶子空了会出现在补货页。

### 统计与画像

- **统计**：一进来先看数字——这段时间消耗了多少克豆子、平均一杯用多少粉、多少毫升酒、酒精大约多少克、喝掉多少钱、买进来多少钱、多少杯；再看曲线和按人拆开。撤回的流水不进任何汇总。补录已喝光的整袋只计克重和钱，不算杯、不算到人。
- **日历**：侧栏「日历」。月视图上点咖啡、下点酒；点日期看当天谁喝了什么、多少克或毫升、花了多少钱。可按人滤。一天从凌晨 4 点算起。撤回的不进点数，点开当天仍能看见并划掉。
- **出表**：统计页和日历都能「出表 CSV」。下一个 zip，里面多张表（UTF-8 BOM，Excel 能直接开）：库存、批次与关袋偏差、流水、杯测、酒瓶、补货、按日、按人、统计汇总。标签在豆库表里。撤回的行在明细里标出来。
- **用户画像**：按人名从流水自动总结爱喝什么样的（浅烘高酸、常点的酒等），并写出这个人喝了多少克豆、多少酒精、花了多少钱。样本太少不强行下结论。
- **更新**：侧栏「更新」用白话记下每次改了什么，最新的在最上面。

### Cursor 用 MCP 直接记账

准备好豆袋照片和豆卡文字后，可以让 **Cursor 经 MCP 直接写入** 小主机上的库，不必在网页里一项项手填。网页和 MCP 走同一套接口与写锁，写完刷新豆库就能看见。网页正在改那张卡时，Cursor 会被拒，不会替你抢锁。

先让网页服务跑着（`start.sh` / `start.bat`）。在仓库根目录复制 `.env.example` 为 `.env`，填登录邮箱和密码。Cursor 打开本仓库后应能看到 `coffeebar` 这个 MCP（`.cursor/mcp.json`）。Windows 直接跑仓库里 `.venv\Scripts\coffeebar-mcp.exe`（Cursor 的 MCP 进程拿不到用户 PATH，写 `uv` / `cmd.exe` 都会红）。红了先完全退出 Cursor 再开，不要只拨开关。Mac 把 `command` 改成 `uv`、`args` 改成 `["run", "coffeebar-mcp"]`。

| 你在 Cursor 里说 | MCP 去做 |
| ---- | ---- |
| 用这张图和下面字段建一张豆卡 | 建豆、建批次、拷照片进 `data/photos/` |
| 给西达摩补开袋实称 198 g | 改当前批次 |
| 我刚才用了 16 g，谁喝的：戚浩辰 | 记消耗流水，并说出扣的是哪一袋 |
| 这袋冲完了 | 关袋并结清偏差（你必须明确说） |
| 豆库还剩哪些浅烘 | 查询列表 |
| 这个月喝了多少豆、多少酒、花了多少钱 | 汇总统计数字 |
| 九月哪天冲过 | 看日历 |
| 把账出到桌面 | 写出 zip |
| 上架一杯金汤力、倒 40 ml | 写配方、摆上酒单、扣对应酒瓶 |

MCP 只连本机（或公司内网）上的 coffeebar，口令与数据不进 Git。完整工具表见 [docs/002](docs/002-🚧-豆子档案与小主机架构.md)「MCP：让 Cursor 接管记账」。配方能查、能换基酒、能删；自制基酒以后补。

## 谁在哪用

| 场景 | 设备 | 差别 |
| ---- | ---- | ---- |
| 日常吧台 | Win11 小主机 + 21 寸屏 + 键鼠 | 宽屏布局，这是主屏 |
| 拍照、站着冲 | iPhone / iPad | 单列、相机和冲煮动画靠前 |
| 换一台电脑 | 公司内网 Mac / Windows | 同一套功能，随窗口变布局 |

功能全端一样，只换布局。同一条豆卡/酒瓶同时只允许一个写会话，避免互踩。自己在另一台机器上开着编辑页时，这边会问「要接管吗」，点一下就能改，不用干等；Cursor 经 MCP 写入则会被直接拦下，让你先去网页保存。

**小主机**：Windows 11，16 GB，Ryzen 7 PRO 7850H + Radeon。既是服务器也是工作台。内网为主。

## 怎么跑

不用 Docker。小主机上只要三个脚本：

1. **装一次**：双击 [`scripts/install.bat`](scripts/install.bat)。会装 uv、同步 Python 依赖、装前端依赖并构建。没有 Node 会提示你去装 LTS。
2. **日常用**：双击 [`scripts/start.bat`](scripts/start.bat)。自动开浏览器，同时打印内网地址，手机连同一个 Wi-Fi 输那个地址就能用。关掉窗口就停。打开后先注册/登录（密码输错可以试 5 次，满了等一分钟）；**这台机器上第一个注册的人会接手已有的豆和酒**，之后再注册的人是空库。登录页可以忘记密码；本机没配邮箱时，重设/验证链接会直接出现在页面上。上云再配 `COFFEEBAR_SMTP_*`，并在 HTTPS 下打开 `COFFEEBAR_COOKIE_SECURE=1`。侧栏可以改密码（这台继续登着，别的设备会被踢）和注销账号；注销会删掉**自己的**豆、酒、照片和流水，不可恢复；不要拿接手真库存的那个号去试。
3. **备份**：小主机双击 [`scripts/backup.bat`](scripts/backup.bat)；Mac / Linux 跑 `bash scripts/backup.sh`。服务开着也能安全导出，库文件和照片打包进用户目录下的 `coffeebar-backup`。
4. **上云**：不能用 GitHub Pages。用 Render 跑 Docker，步骤见 [docs/009-🚧-上云Render.md](docs/009-🚧-上云Render.md)。公网请设邀请码；第一个用邀请码注册的人会接手迁上去的豆和酒。切过去之后小主机不要再开 `start.bat`。

想用 `http://coffee` 这种短地址而不是带端口的，再加 Caddy：`caddy run --config scripts/Caddyfile`。

### 在 Mac / Linux（含这台开发机）

和小主机同一套用法，只是脚本换了后缀：

```bash
bash scripts/install.sh    # 装一次：uv sync + 前端构建
bash scripts/start.sh      # 日常用：http://localhost:8000 ，会打开浏览器
bash scripts/backup.sh     # 备份库和照片到 ~/coffeebar-backup
```

改前端源码要热更新时：

```bash
bash scripts/dev.sh        # 网页 http://localhost:5173 ，API 仍在 :8000
```

也可以手敲：

```bash
uv sync
uv run uvicorn app.main:app --reload
cd web && npm install && npm run dev
```

跑测试与端到端自检：

```bash
uv run pytest                    # 75 个用例：账面、成本快照、撤回、平均粉量、写锁
uv run python scripts/smoke.py   # 对着真在跑的服务走一遍完整场景并打印数字
```

数据都在 `data/`（SQLite + 照片），不入库。换机器：拷仓库 + 拷 `data/` + 再跑一次 `install.bat`。密钥和口令写本机 `.env`，不要提交。

## 技术形态

- 网页：Vite + React + Tailwind v4 + anime.js（冲煮 SVG）。构建产物由服务直接托管，不另起前端进程。
- 服务：FastAPI（uv）+ SQLite（标准库 `sqlite3`，WAL，无 ORM）+ 本地照片目录。
- 入口：默认 `:8000` 直连；想要短地址再上 Caddy。
- MCP：`uv run coffeebar-mcp`，打同一套 FastAPI / 写锁。口令在 `.env`，不入库。
- 视觉：深色 espresso、奶油字、琥珀点缀；样张以 [_Doc/2026-09-04-ui-样张/画像.png](_Doc/2026-09-04-ui-样张/画像.png) 为准。
